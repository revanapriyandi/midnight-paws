# Midnight Paws

A small command-line choose-your-own-adventure game about a lost cat finding its way home through a city at night.

## Play

Requires Node.js 20 or newer.

```sh
npm start
```

Choose a numbered path at each scene. Some paths lead home, while others reveal different endings.

Run the story checks with:

```sh
npm test
```

Built with GitHub Copilot CLI.
